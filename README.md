# The Theory Room: family edition

A self-paced music website for ABRSM and Trinity exams, Grades 1–8, with every room open:
theory lessons and courses, mock exams, aural tests, sight-reading, a scales coach and practice diary,
composer films, instruments, a handbook and an exam guide.

- Open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify).
- Add each player under "Add or rename learners". Progress is saved in the browser on that device.
- The microphone marking (singing, sight-reading, scales) needs a normal browser over https.

Not affiliated with ABRSM or Trinity College London.
